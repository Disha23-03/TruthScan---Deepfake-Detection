# TruthScan: Deepfake Detection System

TruthScan is a deep learning-based deepfake detection system designed to identify manipulated and authentic media using the Xception architecture. The project utilizes transfer learning, computer vision, and machine learning techniques to classify deepfake content from image and video frames.

## Features

* Deepfake detection using Xception CNN architecture
* Face extraction and preprocessing using OpenCV
* Transfer learning-based model training
* Binary classification of real and fake media
* Performance evaluation using Accuracy, Precision, Recall, and ROC-AUC

## Tech Stack

* Python
* TensorFlow
* Keras
* OpenCV
* NumPy
* Pandas
* Matplotlib

## Datasets

* Celeb-DF
* FaceForensics++
* UADFV
* DF-TIMIT
* FakeAVCeleb

## Results

* Accuracy: 95.25%
* Precision: 95.48%
* Recall: 95.00%
* ROC-AUC: 98.37%
* Loss: 0.1814
